# Fases 14.1 + 15 + 16 — Closures Escapadas, ARC Pass, TRMA

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Corrigir o codegen de closures para suportar escaping de fato (14.1), implementar ARC com malloc/free e refcount real sem leak (15), e implementar TRMA no optimizer (16).

**Architecture:**

- **Fase 14.1**: Mover a alocação do CaptureBox do call site para o definition site. O `var_map` segura `box_ptr` (não `func_ptr` cru). No call site, extrai `fn_ptr` do box e faz `call_indirect`.

- **Fase 15**: CaptureBox deixa a arena e passa a usar `malloc`/`free` do C. Refcount real: `incref` ao aliasar/passar como argumento, `decref` ao sair de escopo. Quando refcount → 0, `free` imediato. Sem leak, sem GC.

- **Fase 16**: TRMA como pass TAST no optimizer. Detecta auto-recursão direta com operador associativo (`@associative(0)` em `+`, `@associative(1)` em `*`) e reescreve com acumulador.

**Tech Stack:** Rust, Cranelift 0.133, edition 2024, libc malloc/free.

## Estado atual (verificado em código)

### O bug estrutural (Fase 14.1)

Hoje o codegen faz:
1. `let f := + _ n` → lowera Lambda como `func_ptr` (i64 cru). `var_map[f] = func_ptr`.
2. `f 5` → call site aloca CaptureBox lendo `n` do `var_map` do caller.

Isso quebra se `f` escapa do escopo onde `n` vive (ex: `make_adder` retorna lambda).

### Runtime ARC (Fase 15)

`kata-rt/src/arc.rs` tem `kata_rt_alloc_arc`, `kata_rt_incref`, `kata_rt_decref`.
- `alloc_arc`: aloca na **arena global** (handle 0) via `kata_rt_arena_alloc`. bumpalo — sem free individual.
- `incref`: incrementa refcount, não libera.
- `decref`: decrementa refcount. **NÃO libera quando chega a 0** — comentário diz "Fase 15 ativará free real".

**Mudança necessária:** trocar `kata_rt_arena_alloc` por `malloc` (libc). `decref` chama `free` quando refcount → 0.

### Optimizer (Fase 16)

`kata-optimizer/src/lib.rs` é pass-through (no-op). `optimize(typed) = typed`.

### @associative no resolution

`OverloadInfo.associative_neutral: Option<i64>` já é populado. `+` tem `associative_neutral = Some(0)`. `is_associative` é flag separado em `Signature`. `populate_dispatch_table` em `helpers.rs` já marca `+` e `*` como comutativos.

### Layout do CaptureBox

```
offset 0:  fn_ptr     (i64) — ponteiro da função JIT
offset 8:  refcount   (i64) — contagem de referências (≥1)
offset 16: captures[0] (i64)
offset 24: captures[1] (i64)
...
offset 16 + (n-1)*8: captures[n-1]
```

### Task 2: Mover alocação de CaptureBox para o definition site

**Objective:** Quando `let f := lambda...` é lowerado e o lambda tem captures, alocar o CaptureBox AQUI (no definition site) em vez de no call site. O `var_map[f]` segura `box_ptr`, não `func_ptr`.

**Files:**
- Modify: `crates/kata-codegen/src/lowering/expr.rs` (braço `Lambda`)
- Modify: `crates/kata-codegen/src/lowering/closure.rs` (call site extrai fn_ptr do box)
- Modify: `crates/kata-codegen/src/lowering/mod.rs` (`closure_captures` muda semântica)

**Análise da mudança:**

Hoje:
- Braço `Lambda` em `expr.rs:280-343`: declara função JIT, compila corpo, retorna `func_ptr`.
- Braço `Let` em `expr.rs:213-226`: registra captures em `closure_captures[name]`, lowera value → `func_ptr`, `var_map[name] = func_ptr`.
- Call site `closure.rs:62-108`: lê `func_ptr` do `var_map`, se `closure_captures[name]` existe chama `alloc_capture_box` → `box_ptr`, `call_indirect(func_ptr, [box_ptr, args...])`.

Novo fluxo:
- Braço `Lambda`: declara função JIT, compila corpo, se captures não-vazio chama `alloc_capture_box` AQUI → retorna `box_ptr`. Sem captures → retorna `func_ptr`.
- Braço `Let`: lowera value (já produz `box_ptr` ou `func_ptr`), `var_map[name] = result`. Registra em `closure_captures` (HashSet) quais nomes têm box.
- Call site: se nome está em `closure_captures`, `box_ptr = use_var`, extrai `fn_ptr` via `kata_rt_arc_fn_ptr(box_ptr)`, `call_indirect(fn_ptr, [box_ptr, args...])`. Se não, `func_ptr = use_var`, `call_indirect(func_ptr, [args...])` (caminho atual).

- Se `captures` é não-vazio: `let box_ptr = super::closure::alloc_capture_box(func_ptr, captures, ctx)?; Ok(box_ptr)`
- Se vazio: `Ok(func_ptr)`

**Step 2: Mudar closure_captures para HashSet<String>**

Em `mod.rs`: `closure_captures: HashMap<String, Vec<CaptureInfo>>` → `HashSet<String>`.

Atualizar 3 sites de construção (`mod.rs:143`, `function_def.rs:113`, `action_def.rs:122`):
`closure_captures: HashMap::new()` → `closure_captures: HashSet::new()`.

No braço `Let`: se value é Lambda com captures não-vazio, `ctx.closure_captures.insert(name.clone())`.

**Step 3: Modificar call site em closure.rs**

## Fase 15 — ARC (malloc/free + refcount real)

### Task 4: Trocar CaptureBox para malloc/free

**Objective:** CaptureBox deixa a arena e passa a usar malloc/free do libc. Refcount real com liberação imediata.

**Files:**
- Modify: `crates/kata-rt/src/arc.rs`

**Análise:**

Hoje `kata_rt_alloc_arc` chama `kata_rt_arena_alloc(0, total_size)` (arena global, bumpalo). Sem free individual.

Mudança: usar `libc::malloc` (ou `std::alloc::alloc`) para alocar o CaptureBox. `kata_rt_decref` chama `free` quando refcount → 0.

Os captures dentro do box são i64 — SMI inline, Float bits, ponteiros para arena para Text/Tuple/Sum. Esses ponteiros referenciam a arena global (que vive pelo programa), então o box ser freed não invalida os captures. O problema cross-fiber (capturar ponteiro para arena de fiber morta) é Fio 11.

**Step 1: Modificar kata_rt_alloc_arc para usar malloc**

```rust
use std::alloc::{alloc, dealloc, Layout};

#[unsafe(no_mangle)]
pub extern "C" fn kata_rt_alloc_arc(fn_ptr: i64, captures_ptr: i64, n_captures: i64) -> i64 {
    if n_captures < 0 {
        return 0;
    }

    let total_size = 16 + n_captures * 8;  // header + captures
    let layout = Layout::from_size_align(total_size as usize, 8)
        .expect("invalid layout");

    let box_ptr = unsafe { alloc(layout) } as i64;
    if box_ptr == 0 {
        return 0;  // falha na alocação
    }

    unsafe {
        let ptr = box_ptr as *mut u8;
        std::ptr::write_unaligned(ptr as *mut i64, fn_ptr);
        std::ptr::write_unaligned(ptr.add(8) as *mut i64, 1);  // refcount = 1

        if n_captures > 0 && captures_ptr != 0 {
            let src = captures_ptr as *const i64;
            let dst = ptr.add(16) as *mut i64;
            for i in 0..n_captures as usize {
                let val = std::ptr::read_unaligned(src.add(i));
                std::ptr::write_unaligned(dst.add(i), val);
            }
        }
    }

    box_ptr
}
```

**Step 2: Modificar kata_rt_decref para chamar free**

```rust
#[unsafe(no_mangle)]
pub extern "C" fn kata_rt_decref(box_ptr: i64) -> i64 {
    if box_ptr == 0 {
        return 0;
    }
    unsafe {
        let refcount_ptr = (box_ptr as *mut u8).add(8) as *mut i64;
        let count = std::ptr::read_unaligned(refcount_ptr);
        if count > 0 {
            let new_count = count - 1;
            std::ptr::write_unaligned(refcount_ptr, new_count);
            if new_count == 0 {
                // Libera o box — precisa do n_captures para calcular o tamanho.
                // Como não temos n_captures no box, armazenar como terceiro campo?
                // OU: layout fixo sem n_captures (box não sabe seu próprio tamanho).
                // Solução: armazenar n_captures no offset 0 junto com fn_ptr?
                // Não — layout é fn_ptr(8) + refcount(8) + captures.
                // Alternativa: armazenar n_captures no refcount slot quando count=0?
                // Melhor: adicionar campo n_captures no box.
                // Layout novo: fn_ptr(8) + refcount(8) + n_captures(8) + captures.
                // OU: guardar o Layout globalmente (HashMap<i64, Layout>).
                // Mais simples: layout fixo — guardar n_captures no box.
            }
        }
    }
    0
}
```

**Problema:** Para chamar `dealloc`, precisamos do `Layout` (tamanho + align). O box não guarda `n_captures`. Solução: adicionar `n_captures` como terceiro campo no header.

**Layout novo:**
```
offset 0:  fn_ptr      (i64)
offset 8:  refcount    (i64)
offset 16: n_captures  (i64)
offset 24: captures[0] (i64)
offset 32: captures[1] (i64)
...
```

Total: `24 + n_captures * 8`.

Atualizar `define_function_body` em `function_def.rs` que lê captures do box — offset muda de `16 + i*8` para `24 + i*8`.

Atualizar `kata_rt_arc_fn_ptr` — ainda lê offset 0 (fn_ptr não muda).

**Step 3: Implementar com layout novo**

```rust
#[unsafe(no_mangle)]
pub extern "C" fn kata_rt_alloc_arc(fn_ptr: i64, captures_ptr: i64, n_captures: i64) -> i64 {
    if n_captures < 0 {
        return 0;
    }
    let total_size = 24 + n_captures * 8;  // fn_ptr + refcount + n_captures + captures
    let layout = Layout::from_size_align(total_size as usize, 8)
        .expect("invalid layout");
    let box_ptr = unsafe { alloc(layout) } as i64;
    if box_ptr == 0 {
        return 0;
    }
    unsafe {
        let ptr = box_ptr as *mut u8;
        std::ptr::write_unaligned(ptr as *mut i64, fn_ptr);         // offset 0
        std::ptr::write_unaligned(ptr.add(8) as *mut i64, 1);       // offset 8: refcount = 1
        std::ptr::write_unaligned(ptr.add(16) as *mut i64, n_captures); // offset 16
        if n_captures > 0 && captures_ptr != 0 {
            let src = captures_ptr as *const i64;
            let dst = ptr.add(24) as *mut i64;
            for i in 0..n_captures as usize {
                let val = std::ptr::read_unaligned(src.add(i));
                std::ptr::write_unaligned(dst.add(i), val);
            }
        }
    }
    box_ptr
}

#[unsafe(no_mangle)]
pub extern "C" fn kata_rt_decref(box_ptr: i64) -> i64 {
    if box_ptr == 0 {
        return 0;
    }
    unsafe {
        let refcount_ptr = (box_ptr as *mut u8).add(8) as *mut i64;
        let count = std::ptr::read_unaligned(refcount_ptr);
        if count > 0 {
            let new_count = count - 1;
            std::ptr::write_unaligned(refcount_ptr, new_count);
            if new_count == 0 {
                // Libera o box.
                let n_captures_ptr = (box_ptr as *mut u8).add(16) as *mut i64;
                let n_captures = std::ptr::read_unaligned(n_captures_ptr);
                let total_size = 24 + n_captures * 8;
                let layout = Layout::from_size_align(total_size as usize, 8)
                    .expect("invalid layout");
                dealloc(box_ptr as *mut u8, layout);
            }
        }
    }
    0
}
```

### Task 5: Codegen inline — incref/decref nos pontos apropriados

**Objective:** O codegen emite `incref`/`decref` nos pontos apropriados durante o lowering.

**Files:**
- Modify: `crates/kata-codegen/src/lowering/expr.rs` (braço `Let`)
- Modify: `crates/kata-codegen/src/lowering/closure.rs` (passagem de argumento)
- Modify: `crates/kata-codegen/src/lowering/function_def.rs` (cleanup epílogo)

**Análise dos pontos de incref/decref:**

1. **`incref` ao aliasar** — `let g := f` onde `f` é CaptureBox:
   Antes de `def_var(g, box_ptr)`, emitir `incref(box_ptr)`.

2. **`incref` ao passar como argumento** — `h (g 10)` onde `g` é CaptureBox:
   Antes de `call_indirect`, emitir `incref(arg_box_ptr)` para cada argumento que é CaptureBox.

3. **`decref` ao sobrescrever** — `let f := new_value` onde `f` já existia como CaptureBox:
   Antes de `def_var(f, new_val)`, emitir `decref(old_box_ptr)`.

4. **`decref` ao sair de escopo** — fim de função/Action:
   No epílogo, antes de `return_`, percorrer `var_map` e emitir `decref` para cada CaptureBox viva.

**Implementação:**

O codegen precisa saber quais variáveis no `var_map` são CaptureBox. Usar `closure_captures: HashSet<String>` (da Fase 14.1).

**Step 1: incref no aliasing (braço Let)**

No braço `Let` em `expr.rs`:
```rust
TypedExprKind::Let { name, value } => {
    let val = lower_expr(&value.node, ctx)?;
    
    // Se val é CaptureBox (Lambda com captures), incref.
    if let TypedExprKind::Lambda { captures, .. } = &value.node.kind
        && !captures.is_empty()
    {
        // incref(val) — o box acabou de ser criado com refcount=1,
        // e var_map[name] vai segurar mais uma referência.
        emit_incref(val, ctx)?;
        ctx.closure_captures.insert(name.clone());
    }
    
    // Se name já existia no var_map como CaptureBox, decref do antigo.
    if ctx.closure_captures.contains(name) {
        if let Some(old_var) = ctx.var_map.get(name) {
            let old_val = ctx.builder.use_var(*old_var);
            emit_decref(old_val, ctx)?;
        }
    }
    
    let clif_ty = ty_to_clif(&value.node.ty);
    let var = ctx.new_var(name, clif_ty);
    ctx.builder.def_var(var, val);
    Ok(ctx.builder.ins().iconst(I64, 0))
}
```

**Espera** — há uma subtletza. Quando o braço `Lambda` aloca o box, refcount=1. O `var_map[name]` segura uma referência. Se `f` é usada N vezes no corpo, cada uso precisa de incref? Não — `var_map[name]` é uma referência. O box tem refcount=1 para essa referência. Quando `f` sai de escopo, decref(1) → 0 → free. Se `let g := f` cria um alias, incref → 2. Quando ambos saem de escopo, decref+decref → 0 → free.

O problema: o codegen atual não rastreia "saída de escopo" — funções puras terminam com `return_` direto. Precisa de um epílogo de cleanup.

**Step 2: cleanup epílogo em define_function_body**

Após lowerar o body da função, antes do `return_`:
```rust
// Emitir decref para cada CaptureBox viva no var_map.
for (name, var) in &lower.var_map {
    if lower.closure_captures.contains(name) {
        let val = lower.builder.use_var(*var);
        emit_decref(val, &mut lower)?;
    }
}

// Agora sim, return_.
if !lower.emitted_tail_call {
    lower.builder.ins().return_(&[result]);
}
```

**Atenção:** Se o body emitiu `return_call` (tail call), não há epílogo — o controle vai embora. Nesse caso, os CaptureBox locais não são decref'd. Isso é um leak. Solução: emitir decref ANTES do tail call, ou aceitar leak em tail calls (o callee "herda" as referências?). Decisão: emitir decref antes do tail call se possível, senão documentar como limitation.

**Step 3: incref ao passar como argumento**

No call site `closure.rs`, para cada argumento que é `Ident` cujo nome está em `closure_captures`:
```rust
for arg in args {
    if let TypedExprKind::Ident { name } = &arg.node.kind {
        if ctx.closure_captures.contains(name) {
            let arg_val = lower_expr(&arg.node, ctx)?;
            emit_incref(arg_val, ctx)?;  // callee pode manter referência
            arg_values.push(arg_val);
            continue;
        }
    }
    let val = lower_expr(&arg.node, ctx)?;
    arg_values.push(val);
}
```

```rust
fn emit_incref(val: Value, ctx: &mut LowerCtx) -> Result<(), CodegenError> {
    let incref_ref = ctx.ffi_refs.get("kata_rt_incref")
        .ok_or_else(|| CodegenError::FfiSymbolNotFound("kata_rt_incref".into()))?;
    ctx.builder.ins().call(*incref_ref, &[val]);
    Ok(())
}

fn emit_decref(val: Value, ctx: &mut LowerCtx) -> Result<(), CodegenError> {

        .ok_or_else(|| CodegenError::FfiSymbolNotFound("kata_rt_decref".into()))?;
    ctx.builder.ins().call(*decref_ref, &[val]);
    Ok(())
}
```

### Task 9: Implementar TRMA pass

**Objective:** Detectar auto-recursão direta com operador associativo e reescrever para recursão de cauda com acumulador.

**Files:**
- Modify: `crates/kata-optimizer/src/lib.rs`
- Create: `crates/kata-optimizer/src/trma.rs`

**Análise:**

TRMA reescreve:
```kata
soma n:
    match n
        0: 0
        otherwise: + n (soma (- n 1))
```
Para:
```kata
soma n:
    soma_acc n 0

soma_acc n acc:
    match n
        0: acc
        otherwise: soma_acc (- n 1) (+ acc n)
```

**Estrutura do pass:**

1. Para cada `TypedFunction` no `TypedModule`:
   a. Verificar se tem 1 parâmetro.
   b. Analisar as cláusulas: body é `Match` com um braço recursivo envolto por operador associativo.
   c. Detectar o padrão: `op arg1 (self_call arg2)` onde `op` é associativo.
   d. Reescrever: criar função `_acc` com parâmetro extra (acumulador), trocar chamada recursiva por tail call com `acc op arg1`.

2. **Detecção do padrão na TAST:**

   Uma cláusula da função `soma` tem:
   - `patterns = [Ident("n")]`
   - `body = Match { scrutinee: Ident("n"), arms: [...] }`
   - Arm `otherwise`: `Closure { callee: Ident("+"), args: [Ident("n"), Closure { callee: Ident("soma"), args: [...] }] }`

   O pass precisa:
   - Identificar que `+` é associativo (consultar DispatchTable).
   - Identificar que `soma` chama `soma` (auto-recursão direta).
   - Extrair: `op = +`, `non_rec_arg = n` (não-recursivo), `rec_arg = (- n 1)` (argumento da chamada recursiva).
   - `associative_neutral` do `+` no DispatchTable é `Some(0)` — valor inicial do acumulador.

3. **Transformação da TAST:**

   Criar nova `TypedFunction` `soma_acc`:
   - `param_types = [Int, Int]` (n, acc)
   - `ret_ty = Int`
   - 1 cláusula: `patterns = [Ident("n"), Ident("acc")]`
   - body: `Match` com:
     - Arm `Literal(0)`: body = `Ident("acc")`
     - Arm `otherwise`: body = `Closure { callee: Ident("soma_acc"), args: [Closure { callee: Ident("-"), args: [Ident("n"), IntLit("1")] }, Closure { callee: Ident("+"), args: [Ident("acc"), Ident("n")] }] }`

   Reescrever `soma`:
   - 1 cláusula: `patterns = [Ident("n")]`
   - body: `Closure { callee: Ident("soma_acc"), args: [Ident("n"), IntLit("0")] }`

4. **Registro no DispatchTable:**

   `soma_acc` precisa ser declarada no JITModule pelo codegen. A função é criada pelo optimizer e inserida em `TypedModule.functions`. O codegen já percorre `typed.functions` e declara cada uma. `soma_acc` aparece naturalmente.

   Mas `soma_acc` não está no `DispatchTable` — o codegen a encontra via `kata_ids` (declarada como função JIT). Verificar que `define_kata_function` é chamada para `soma_acc`.

**Step 1: Criar trma.rs com detecção e reescrita**

```rust
// crates/kata-optimizer/src/trma.rs

use kata_core::dispatch::DispatchTable;
use kata_core::ty::{PrimTy, Ty};
use kata_inference::{
    TypedExpr, TypedExprKind, TypedFunction, TypedLambdaClause, TypedMatchArm,
    TypedModule, TypedPattern,
};
use kata_ast::Span;

/// Padrão TRMA detectado numa função.
struct TrmaPattern {
    /// Nome da função recursiva (ex: "soma").
    func_name: String,
    /// Operador associativo (ex: "+").
    op: String,
    /// Elemento neutro (ex: 0).
    neutral: i64,
    /// Argumento não-recursivo do operador (ex: Ident("n")).
    non_rec_arg: TypedExprKind,
    /// Argumento passado para a chamada recursiva (ex: (- n 1)).
    rec_arg: TypedExprKind,
    /// Pattern do caso base (ex: Literal(0)).
    base_pattern: TypedPattern,
    /// Valor retornado no caso base (ex: IntLit("0") ou Ident que não é a chamada recursiva).
    base_value: TypedExprKind,
}

/// Verifica se uma função é candidata a TRMA.
fn is_trma_candidate(
    func: &TypedFunction,
    table: &DispatchTable,
) -> Option<TrmaPattern> {
    // 1. Tem exatamente 1 parâmetro.
    if func.param_types.len() != 1 {
        return None;
    }

    // 2. Tem exatamente 1 cláusula.
    if func.clauses.len() != 1 {
        return None;
    }

    let clause = &func.clauses[0];

    // 3. O body é Match.
    let body = &clause.body.node;
    let arms = match &body.kind {
        TypedExprKind::Match { scrutinee, arms } => arms,
        _ => return None,
    };

    // 4. Procurar: um arm é caso base (não-recursivo), outro é recursivo com op associativo.
    let mut base_arm = None;
    let mut rec_arm = None;

    for arm in arms {
        let body = &arm.body.node;
        if is_recursive_call(&body.kind, &func.name) {
            rec_arm = Some(arm);
        } else {
            base_arm = Some(arm);
        }
    }

    let base_arm = base_arm?;
    let rec_arm = rec_arm?;

    // 5. O arm recursivo é `op(arg1, self_call(arg2))` onde op é associativo.
    let rec_body = &rec_arm.body.node;
    match &rec_body.kind {
        TypedExprKind::Closure { callee, args, .. } => {
            let op_name = extract_ident_name(&callee.node.kind)?;
            
            // Verificar que op é associativo no DispatchTable.
            let overloads = table.get_overloads(&op_name)?;
            let overload = overloads.first()?;
            let neutral = overload.associative_neutral?;

            // Um dos args é a chamada recursiva, o outro não é.
            if args.len() != 2 {
                return None;
            }
            let arg0 = &args[0].node.kind;
            let arg1 = &args[1].node.kind;

            let (non_rec_arg, rec_arg) = if is_recursive_call(arg1, &func.name) {
                (arg0.clone(), arg1.clone())
            } else if is_recursive_call(arg0, &func.name) {
                (arg1.clone(), arg0.clone())
            } else {
                return None;
            };

            // Extrair o argumento da chamada recursiva.
            let rec_arg_expr = match &rec_arg {
                TypedExprKind::Closure { args, .. } => {
                    args.first()?.node.kind.clone()
                }
                _ => return None,
            };

            Some(TrmaPattern {
                func_name: func.name.clone(),
                op: op_name,
                neutral,
                non_rec_arg,
                rec_arg: rec_arg_expr,
                base_pattern: base_arm.pattern.clone()?.node.clone(),
                base_value: base_arm.body.node.kind.clone(),
            })
        }
        _ => None,
    }
}

/// Verifica se expr é uma chamada recursiva para `func_name`.
fn is_recursive_call(kind: &TypedExprKind, func_name: &str) -> bool {
    match kind {
        TypedExprKind::Closure { callee, .. } => {
            if let TypedExprKind::Ident { name } = &callee.node.kind {
                name == func_name
            } else {
                false
            }
        }
        _ => false,
    }
}

fn extract_ident_name(kind: &TypedExprKind) -> Option<String> {
    match kind {
        TypedExprKind::Ident { name } => Some(name.clone()),
        _ => None,
    }
}

/// Reescreve a função com acumulador.
fn rewrite_with_accumulator(
    func: &TypedFunction,
    pattern: &TrmaPattern,
) -> (TypedFunction, TypedFunction) {
    let acc_name = format!("{}_acc", func.name);
    let param_ty = func.param_types[0].clone();
    let ret_ty = func.ret_ty.clone();

    // nova função original: chama _acc com (n, neutral)
    let original = TypedFunction {
        name: func.name.clone(),
        param_types: func.param_types.clone(),
        ret_ty: ret_ty.clone(),
        clauses: vec![TypedLambdaClause {
            patterns: func.clauses[0].patterns.clone(),
            body: Spanned::new(
                TypedExpr {
                    span: Span::synthetic(),
                    ty: ret_ty.clone(),
                    tail_pos: true,
                    effect: kata_inference::Effect::Puro,
                    kind: TypedExprKind::Closure {
                        callee: Box::new(Spanned::new(
                            TypedExpr {
                                span: Span::synthetic(),
                                ty: Ty::Function(
                                    vec![param_ty.clone(), param_ty.clone()],
                                    Box::new(ret_ty.clone()),
                                ),
                                tail_pos: false,
                                effect: kata_inference::Effect::Puro,
                                kind: TypedExprKind::Ident { name: acc_name.clone() },
                            },
                            Span::synthetic(),
                        )),
                        args: vec![
                            Spanned::new(
                                TypedExpr {
                                    span: Span::synthetic(),
                                    ty: param_ty.clone(),
                                    tail_pos: false,
                                    effect: kata_inference::Effect::Puro,
                                    kind: TypedExprKind::Ident {
                                        name: func.clauses[0].patterns[0]
                                            .node
                                            .ident_name()
                                            .unwrap_or("n").to_string(),
                                    },

                                    span: Span::synthetic(),

                                        text: pattern.neutral.to_string(),
                                    },
                                },
                                Span::synthetic(),
                            ),
                        ],
                        ffi_symbol: None,
                    },
                },
                Span::synthetic(),
            ),
            guards: vec![],
            with_bindings: vec![],
        }],
    };

    // função _acc: match n { base: acc, otherwise: _acc(rec_arg, op(acc, non_rec_arg)) }
    let acc_func = TypedFunction {

        param_types: vec![param_ty.clone(), param_ty.clone()],
        ret_ty: ret_ty.clone(),
        clauses: vec![TypedLambdaClause {
            patterns: vec![
                Spanned::new(
                    TypedPattern::Ident { name: "n".into(), ty: param_ty.clone() },
                    Span::synthetic(),
                ),
                Spanned::new(
                    TypedPattern::Ident { name: "acc".into(), ty: param_ty.clone() },
                    Span::synthetic(),
                ),
            ],
            body: Spanned::new(
                TypedExpr {
                    span: Span::synthetic(),
                    ty: ret_ty.clone(),
                    tail_pos: true,
                    effect: kata_inference::Effect::Puro,
                    kind: TypedExprKind::Match {
                        scrutinee: Box::new(Spanned::new(
                            TypedExpr {
                                span: Span::synthetic(),
                                ty: param_ty.clone(),
                                tail_pos: false,
                                effect: kata_inference::Effect::Puro,
                                kind: TypedExprKind::Ident { name: "n".into() },
                            },
                            Span::synthetic(),
                        )),
                        arms: vec![
                            // caso base: retorna acc
                            TypedMatchArm {
                                pattern: Some(Spanned::new(
                                    pattern.base_pattern.clone(),
                                    Span::synthetic(),
                                )),
                                guard: None,
                                body: Spanned::new(
                                    TypedExpr {
                                        span: Span::synthetic(),
                                        ty: ret_ty.clone(),
                                        tail_pos: true,
                                        effect: kata_inference::Effect::Puro,
                                        kind: TypedExprKind::Ident { name: "acc".into() },
                                    },
                                    Span::synthetic(),
                                ),
                            },
                            // caso recursivo: _acc(rec_arg, op(acc, non_rec_arg))

                                pattern: None, // otherwise
                                guard: None,
                                body: Spanned::new(
                                    TypedExpr {
                                        span: Span::synthetic(),
                                        ty: ret_ty.clone(),
                                        tail_pos: true,
                                        effect: kata_inference::Effect::Puro,
                                        kind: TypedExprKind::Closure {
                                            callee: Box::new(Spanned::new(
                                                TypedExpr {
                                                    span: Span::synthetic(),
                                                    ty: Ty::Function(
                                                        vec![param_ty.clone(), param_ty.clone()],
                                                        Box::new(ret_ty.clone()),
                                                    ),
                                                    tail_pos: false,
                                                    effect: kata_inference::Effect::Puro,
                                                    kind: TypedExprKind::Ident {
                                                        name: format!("{}_acc", func.name),
                                                    },
                                                },
                                                Span::synthetic(),
                                            )),
                                            args: vec![
                                                // rec_arg (ex: (- n 1))
                                                Spanned::new(
                                                    TypedExpr {

                                                        effect: kata_inference::Effect::Puro,

                                                                        vec![param_ty.clone(), param_ty.clone()],
                                                                        Box::new(ret_ty.clone()),

                                                                        name: pattern.op.clone(),

                                                                        ty: param_ty.clone(),
                                                                        tail_pos: false,
                                                                        effect: kata_inference::Effect::Puro,

/// Pass TRMA — percorre funções e reescreve candidatas.
pub fn trma_pass(typed: &mut TypedModule) {
    let mut new_functions = Vec::new();
    for func in &typed.functions {
        if let Some(pattern) = is_trma_candidate(func, &typed.dispatch_table) {
            let (rewritten, acc) = rewrite_with_accumulator(func, &pattern);
            new_functions.push(rewritten);
            new_functions.push(acc);
        } else {
            new_functions.push(func.clone());
        }
    }
    typed.functions = new_functions;
}
```
